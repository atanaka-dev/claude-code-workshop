# Visual Quality Rules

## Purpose

HTML資料の見た目と読みやすさを安定させるためのルール。

## Common Rules

- 余白を十分に取る
- 見出し、本文、補足の階層を明確にする
- 同じ種類の情報は同じ見た目で表現する
- 情報量が多い場合は分割する
- 装飾より理解しやすさを優先する

## Slide Quality

- 1スライド1メッセージ
- 主要ブロックは最大3つ
- 箇条書きは最大5点
- 本文は短くする
- 文字サイズは投影で読める大きさにする
- スライド下部に現在位置を表示する

## Notes Quality

- 目次を設置する
- 見出し階層を守る
- 長いセクションは分割する
- コードブロックは横スクロール可能にする
- 表はスマホでも破綻しないようにする

## Color

- `DESIGN.md` のカラーパレットのみ使う
- 重要な意味を色だけで伝えない
- コントラストを確保する
- 警告色を多用しない

## Typography

- 見出しは明確に大きくする
- 本文サイズは読みやすくする
- 補足情報は小さくしてよいが、読めないサイズにしない
- 太字を使いすぎない

## Layout Review Checklist

- [ ] 情報が詰まりすぎていない
- [ ] 見出しと本文の階層が明確
- [ ] 余白が十分
- [ ] 色が増えすぎていない
- [ ] 文字が小さすぎない
- [ ] スマホ幅でも最低限読める
- [ ] PC幅で横に広がりすぎない
- [ ] GitHub Pages上で崩れない
