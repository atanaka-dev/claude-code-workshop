# Citation Rules

## Purpose

資料内の事実、数値、外部仕様、製品仕様に対して、出典を明確にする。

## When Citation Is Required

以下には出典を付ける。

- 外部サービスの仕様
- GitHub Pagesの制約
- Claude Codeの仕様
- 製品機能
- 価格
- 法律・規制
- 統計情報
- 市場情報
- 会社情報
- 日付に依存する情報
- 変更される可能性がある情報

## Source File

出典は `docs/references.md` に記録する。

## Slide Citation

スライドでは、画面下部に小さく出典名を表示する。

例:

```text
Source: GitHub Docs
Notes Citation
```

notes.htmlでは、該当セクションの近くに参考リンクを置く。

## Prohibited

- 出典なしで数値を断定する
- 未確認情報を事実として書く
- 公式情報と推測を混ぜる
- 古い情報を最新情報として扱う

## If Source Is Insufficient

出典が十分でない場合は、以下のように書く。

```text
この点は出典だけでは確認できないため、追加確認が必要。
```
