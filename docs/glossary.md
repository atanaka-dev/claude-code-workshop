# Glossary

## Claude Code

コードベース上でファイル作成、編集、調査、実行を行えるAIコーディング支援環境。

## GitHub Pages

GitHubリポジトリから静的Webサイトを公開する機能。

## Slide Deck

発表用のスライド資料。

## Notes

後読み用の縦スクロール資料。

## Design System

色、フォント、余白、コンポーネント、レイアウト方針などを定義したデザインルール。

## Relative Path

現在のHTMLファイルを基準にしたパス。

例:

```html
<link rel="stylesheet" href="./assets/css/base.css">
```

## Root Absolute Path

ドメインのルートを基準にしたパス。

例:

```html
<link rel="stylesheet" href="/assets/css/base.css">
```

GitHub Pagesのプロジェクトサイトでは壊れる可能性があるため、このプロジェクトでは禁止する。
